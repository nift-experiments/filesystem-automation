# Fairness checklist

No core changes or native helper shortcut. Same source/destination bytes and reset policy. Supported cells must pass exact row comparison and SHA-256 output-tree oracle. API metadata/ordering differences are disclosed. Optional features absent from Nift are not emulated using external tools. Fresh and booted isolated boundaries are separate. No overall score. Write/copy and hash algorithms are identified explicitly; results do not establish disk performance or cryptographic security of the portable checksum.
